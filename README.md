# mmods

Minecraft mods by Elliott and son.

## Find Your Path (`find-your-path/`)
A friendly guide for brand-new players: pick a play style (Builder, Explorer, Adventurer, Engineer, Homesteader) and learn Minecraft one small step at a time. Fabric mod for Minecraft Java 26.2.

Every push to `main` builds the mod. The finished `.jar` and build log are saved to the `ci-output` branch.
